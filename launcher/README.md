# Infinite Ascension Launcher

Le launcher PC est prévu pour être l'unique point d'entrée utilisateur : il vérifie la dernière release GitHub, télécharge la version correspondant à la plateforme, vérifie l'intégrité puis lance l'exécutable.

Le self-update de l'exécutable ne doit pas être effectué pendant que le jeu tourne. Le launcher est responsable du remplacement des fichiers.
